# Movimentações Simples/ Múltipla - **Rotina Movimentações Internas - Módulo Estoque/Custos**

O cadastro de Movimentações Internas feitas no Protheus é feito via **"Módulo 06 - Estoque/Custos"**.

De forma mais técnica, as informações cadastradas no Protheus é feita pela rotina padrão **MATA241.PRW** e suas informações podem ser encontradas na tabelas **"Tabela de Movimentações Internas - SD3"**.

**Obs: A rotina permite o lançamento de movimentações internas de materias na forma de requisição ou devolução, atualizando saldo físico, saldo financeiro.**.

[SD3 - Movimentações Internas | ERP Labs](https://erplabs.com.br/SD3)
